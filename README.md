# Lógica de Programação para Web

Este repositório reúne os estudos, exercícios e projetos desenvolvidos durante o curso **Lógica de Programação para Web**.

## 📚 Sobre o curso

O curso aborda os principais conceitos de lógica de programação e algoritmos, desenvolvendo o raciocínio lógico e o pensamento crítico para a resolução de problemas computacionais.

Durante os estudos, foram praticados conceitos fundamentais utilizando **JavaScript**, como:

- Variáveis e operadores
- Estruturas condicionais
- Estruturas de repetição
- Construção de algoritmos
- Algoritmos de seleção e ordenação
- Resolução de problemas por meio da lógica de programação

## 🎯 Objetivo

Desenvolver uma base sólida em lógica de programação, preparando para o aprendizado de linguagens e tecnologias voltadas ao desenvolvimento web.

## 🛠️ Tecnologias utilizadas

- JavaScript
- HTML
- Visual Studio Code

## 📂 Conteúdo

Este repositório contém exercícios, desafios e exemplos práticos realizados ao longo do curso para fixação dos conceitos estudados.
